## Java Time Explorer
Simple Java program that demonstrates various Date/Time features.
### Features Demonstrated
- LocalDateTime Class
- ZonedDateTime Class
- DateTimeFormatter Class
- Duration Class
- Period Class
- Among others
### Instructions 
Open the program with the terminal and run the commands `javac Main.java` and `java Main`
